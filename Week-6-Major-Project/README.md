## Project Overview

This project is about a machine learning model for credit card fraud detection. It aims to improve the performance of classification model by encountering the problem of class imbalance by generating more samples.

## Dataset

- Source: Kaggle
- Link: [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

## Technical Architecture

- Step 1: Load dataset and perform EDA
- Step 2: Data preprocessing
- Step 3: Synthetic data genration and data augmentation
- Step 4: Model training
- Step 5: Compare models for real and augmented data.

## Tech Stack

- Programming Language(s): Python
- Libraries: pandas, seaborn, matplotlib, joblib, CTGAN, XGBoost
- Notebook: Jupyter
- Deployment(UI): Streamlit

## Getting Started

I. To get a local copy up and running, follow these steps:

1. **Clone the repo**
   ```bash
   git clone https://github.com/sahiladlakha33/GNCIPL-Internship-Projects.git
   ```
2. **Navigate to the project directory**
   ```bash
   cd GNCIPL-Internship-Projects/Week-6-Major-Project
   ```
3. **Install dependencies**
   ```bash
   # example for Node.js
   npm install
   # or for Python
   pip install -r requirements.txt
   ```
4. **Run the application**
   ```bash
   # example for Node.js
   npm start
   # or for Python
   python main.py
   ```
II. URL: [Credit Card Fraud Detection Web App](https://credit-card-fraud-detection-myapp.streamlit.app/#credit-card-fraud-detection)
