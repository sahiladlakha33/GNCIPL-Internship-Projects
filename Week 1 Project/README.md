# GNCIPL Internship Week 1 Project

**Submitted by:** Sahil Adlakha

## Project Title
Olympic Medal Count by Country

## Domain
Sports Analytics

## Description
This project analyzes and compares country-wise medal performance across different Olympic years using data from the Olympics (1896-2024). The analysis focuses on:
- Total medals won by top countries over time
- Bar plots to visualize yearly and country-wise dominance
- Heatmaps and time series visualization for medal distribution

## Dataset
- **Source:** Kaggle
- **File:** `Olympics (1896-2024).csv`

## Key Analyses
- Top 10 countries by total medals across all years
- Top 5 countries per Olympic year (2000-2024)
- Total Olympic medals awarded over time
- Heatmap of medal distribution by country and year

## How to Run
1. Clone this repository.
2. Place the dataset (`Olympics (1896-2024).csv`) in the `Week 1 Project` directory.
3. Open and run the notebook:  
   [`GNCIPL Week 1 Project 1.ipynb`](./GNCIPL%20Week%201%20Project%201.ipynb)
